# 行内补全当前实现（2026-09-07）

行内 AI 在光标位置预测续写，用户通过灰字预览并按 Tab 接受。模型根据现有代码、注释中的意图、相关声明推测内容；客户端筛选展示机会与返回结果。云端模型本身由服务端选择，本次没有更换模型。

## 触发与上下文

- 仅真实 `file` 编辑器参与；当前单光标、无选区才能补全。切换编辑器、移动光标、文档变更后，不展示旧请求结果。
- 输入停顿默认等待 300ms，空白行 450ms。空文件、单个孤立字母、已结束语句、标识符中间不自动请求；函数体、表达式、循环头、意图注释后仍可触发。
- 删除、撤销、重做、多点修改和大段粘贴后不自动请求；继续输入重新启用。手动 `editor.action.inlineSuggest.trigger` 绕过这些自动时机限制和拒绝冷却。
- 发给模型的当前文件 prefix/suffix 默认分别为 12000/4000 字符，保留原文。长文件被截掉的全局声明可作为片段补回。
- 云端请求另带最多 3 段、每段不超过 2000 字符的真实源码。候选来自最近打开的最多 20 个同工作区文档，以 include/import、对应头文件、光标附近标识符选择相关声明窗口。配置、凭据、依赖、生成目录和无关源码不进入该集合；不会主动扫描或读取未打开文件。
- LM Studio 仍使用原生 DeepSeek FIM 前后缀；相关文件片段通过已有云端 `context` 协议传送。没有新增服务端接口。

## 候选质量与复用

- 根据实际缓冲区生成预测；不把 IntelliSense 默认首项当作用户意图。若列表打开，只有结果真正延伸所选项时才使用它的替换范围显示，禁止强行拼接无关内容。
- 去除 Markdown fence、模型控制标记、完整行复述、与下一行相同的内容、已存在的 suffix，以及自动触发时仅标点/空白或重复上一语句的结果。尾部括号裁剪检查生成片段的嵌套，保留 `consume(readSensor())` 这类合法调用。
- 缓存与在途复用隔离文档、语言、候选起点/文本和相关片段；本地完整 prefix 用于判断用户是否沿建议输入，截断窗口滑动不会打断复用。本地文档 URI、完整 prefix 与候选标识不发送后端。
- 正常缓存保留 30 秒，空结果保留 1.5 秒。拒绝/忽略后 30 秒内，同上下文不会自动重发，相同文本的剩余续写也被抑制；手动调用可重试。
- 保留串行请求、已发请求正常结束、500ms 默认请求完成后间隔及 429/配额冷却。

## 验证

运行 `npm run test:inline-completion`、`npm run check-build` 和 Vite 生产构建。测试覆盖真实 provider 注册/事件回调以及纯策略、上下文与 transport；provider 测试替换网络边界，不能作为真实云端模型效果或 Electron 键盘操作的验收。

人工验收可在包含相关头文件的 Coder 工程中进行：

1. 在函数体内新增空行，或输入描述意图的注释后换行，检查预测使用已有变量/API。
2. 输入 `for (int i = 0;`，检查循环条件续写仍可出现。
3. 在 `consume(|)` 中补 `readSensor()`，按 Tab 后应为 `consume(readSensor())`。
4. 在 `Serial.be` 且候选为 `begin` 时，检查只展示兼容的 `begin(...)`，不会拼入 `println(...)`。
5. 按 Esc 拒绝，再停顿或移动光标，检查建议不立即重现；手动触发应可重试。
6. 在超过 12000 字符的文件内沿灰字继续输入，检查复用剩余内容；换文件、候选或相关声明后重新预测。
