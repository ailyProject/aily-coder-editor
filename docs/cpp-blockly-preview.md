# Coder 的 C++ ↔ Blockly 编辑器

在 `.cpp`、`.cc`、`.cxx`、`.ino` 及 `.h`、`.hpp`、`.hh`、`.hxx` 文件编辑器右上角点击 **C++：打开 Blockly 转换预览**，同一编辑器组打开对应的 Blockly 预览标签页。重复点击复用该文件的预览。点击 **返回源码** 恢复源文件。选中积木后，可在下方属性面板定位原始源码。转换读取当前编辑器缓冲区，包含未保存修改。

## 实现范围

- 路径为 `C++ → Tree-sitter C++ / WASM → 预览积木数据 → Blockly workspace`，无需 ABS、联网转换或 AI 服务。
- 函数、命名空间、类/结构体、模板、lambda 回调、条件编译分支、switch/case、指针/数组/多变量声明、构造与列表初始化、下标、三元表达式、类型转换、成员访问和链式调用均有结构化表示。循环头与尾保留 C++ 文本，避免错误简化比较符、类型、步长等。
- 支持数组声明后的 Arduino `PROGMEM` 标记：仅在解析副本中以等长空白适配，积木与源码定位始终使用原文。不会在注释/字符串中替换，也不会删除名为 `PROGMEM` 的普通变量。
- 长原始字符串和超过 24 项的纯字面量数组转为数据积木，显示字符/行数或元素数量；完整原文保存在源码映射与数据字段中，可在属性面板查看和编辑。包含函数调用等表达式的数组继续展开，不隐藏执行逻辑。
- 未覆盖语法（如当前的 try/catch）仍以橙色原文积木保留，并提供定位诊断。字段值保留完整原文，长度限制只作用于显示。
- 语法错误显示诊断及空画布；空文件显示空状态。解析在 Worker 内运行，有 15 秒超时、200,000 字符和 2,000 积木限制。源码改变、重新转换、关闭预览时取消旧任务，避免旧结果覆盖新内容。
- 提供刷新、缩放、适应画布和源码列表。范围选择器支持整个文件、函数、类/命名空间、模板和单独回调；较大程序默认显示 `setup` 或首个函数。整个文件视图仍可查看全部积木。刷新保持查看范围，签名相同的多个 lambda 通过源码内容及位置区分。

## 编辑与回写

- 左侧 toolbox 提供 **调用、控制、变量、运算、函数、C++ 原文** 六类积木。可拖入新语句、表达式、函数、lambda，连接、删除和调整执行顺序。
- 点击白色字段直接编辑数值、名称、签名、声明、运算符或循环条件；选中积木后打开 **积木属性**，可编辑完整多行原文、宏、注释和折叠的数据。调用参数数量和 `else` 分支可通过属性按钮或右键菜单调整。
- **撤销 / 重做** 操作当前画布；**生成 C++** 显示完整文件的草稿；**应用到源码** 先在 Worker 中检查生成代码语法，再作为一次可撤销编辑写入原文件缓冲区。返回源码后可撤销、正常保存；在积木标签中保存或关闭时选择“保存”，也会验证、应用并保存源文件。
- 切换函数范围或源码标签会保留草稿。单函数视图固定外层容器，避免意外脱离原位置；新积木必须连接到该容器。未连接表达式、必填插槽缺失、语法错误或无法安全重建的注释边界会阻止应用，并保留草稿。
- 修改过的积木标签显示未保存标记，关闭时使用编辑器原有保存/不保存/取消提示。重新载入需要明确点击 **放弃草稿并载入**。草稿属于当前编辑器会话，尚未提供应用重启后的草稿恢复；需要持久保存时使用保存操作。
- 源码同时被用户或其他功能修改时保留积木草稿并禁用应用。提交前同步比较源文件版本和完整文本，不会覆盖新版本；验证期间继续编辑积木也会停止旧提交。

### 生成策略与边界

转换结果保存原始源码区间、完整字段和子节点插槽。未修改的部分直接复用原文；修改字段或连接时，只重建相应范围。新增代码使用 C++ 生成器；重排表达式时补上必要括号，无花括号的单语句分支扩展为多语句后自动添加花括号。整个文件中的其他函数、HTML、`PROGMEM` 和点阵数据不会因局部修改而重新格式化。新加的复杂语法也可通过原文积木表达。

采用专用 `cpp_preview_*` 积木，不自动匹配 Aily 硬件库积木，不产生 `.abi`，不运行旧 Arduino 生成器。语法检查不能替代工程编译、类型检查或硬件行为验证。未覆盖语法可以原文方式编辑，不能保证全部 C++ 都能细分为结构化积木。

## 代码入口

- `src/features/cppBlocklyPreview.workbench.ts`：编辑器按钮、预览页、文档缓冲区和源码定位。
- `src/features/cppBlockly/`：转换器、源码区间映射、生成器、toolbox、会话草稿、Worker、积木定义、画布和测试。
- `src/main.common.ts`：注册预览功能。
- `src/embedWorkbenchStyles.ts`：移除隐藏整个编辑器操作栏的旧规则，同时恢复 Markdown 的已有预览入口。

Blockly 和解析器在打开预览后按需加载，与主软件原有 Blockly/ABS 工作区隔离。入口位于 Coder 子应用，没有修改 Angular 主软件代码。
