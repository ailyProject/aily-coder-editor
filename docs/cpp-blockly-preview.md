# Coder 的 C++ ↔ Blockly 编辑器

在 `.cpp`、`.cc`、`.cxx`、`.ino` 及 `.h`、`.hpp`、`.hh`、`.hxx` 文件编辑器右上角点击 **C++：打开 Blockly 转换预览**，同一编辑器组打开对应的 Blockly 预览标签页。重复点击复用该文件的预览。点击 **返回源码** 恢复源文件。CPP 与对应预览分栏显示时，源码光标与积木选中/修改双向高亮，目标不在视野内时自动滚动；保留当前编辑焦点。选中积木后，也可在下方属性面板定位原始源码。转换读取当前编辑器缓冲区，包含未保存修改。

## 实现范围

- 路径为 `C++ → Tree-sitter C++ / WASM → 预览积木数据 → Blockly workspace`，无需 ABS、联网转换或 AI 服务。
- 函数、命名空间、类/结构体、模板、lambda 回调、条件编译分支、switch/case、指针/数组/多变量声明、构造与列表初始化、下标、三元表达式、类型转换、成员访问和链式调用均有结构化表示。循环头与尾保留 C++ 文本，避免错误简化比较符、类型、步长等。
- 支持数组声明后的 Arduino `PROGMEM` 标记：仅在解析副本中以等长空白适配，积木与源码定位始终使用原文。不会在注释/字符串中替换，也不会删除名为 `PROGMEM` 的普通变量。
- 长原始字符串和超过 24 项的纯字面量数组转为数据积木，显示字符/行数或元素数量；完整原文保存在源码映射与数据字段中，可在属性面板查看和编辑。包含函数调用等表达式的数组继续展开，不隐藏执行逻辑。
- 未覆盖语法（如当前的 try/catch）仍以橙色原文积木保留，并提供定位诊断。字段值保留完整原文，长度限制只作用于显示。
- 语法错误显示诊断及空画布；空文件显示空状态。解析在 Worker 内运行，有 15 秒超时、200,000 字符和 2,000 积木限制。源码改变、重新转换、关闭预览时取消旧任务，避免旧结果覆盖新内容。
- 提供刷新、缩放、适应画布和源码列表。范围选择器支持整个文件、函数、类/命名空间、模板和单独回调；首次打开始终默认显示整个文件，复杂大文件也不自动切换到 `setup`。刷新和返回预览保持用户选择的范围，签名相同的多个 lambda 通过源码内容及位置区分。

## 编辑与回写

- 左侧 toolbox 提供 **逻辑、循环、数学、文字、数组、变量、自定义函数、I/O引脚、时间、串口、中断、自定义代码** 十二类积木。可拖入新语句、表达式、函数、lambda，连接、删除和调整执行顺序。分类采用主软件 Blockly 模式的图标、40px 行高、侧栏背景和整行选中样式，适配浅色与深色主题；顶部可按分类名、函数名或字段内容搜索，Esc 清空搜索。
- 基础分类下方显示当前项目已安装的库。读取活动 npm 依赖与 `sketch/libraries` 的公开 C++ 头文件，列出可拖入的构造、函数、公开方法、枚举及常量积木；保留重载签名和默认参数。搜索覆盖全部已索引接口，大库每页最多 40 个积木。使用库积木时自动补齐缺少的头文件，实例名及参数需要按当前程序填写。
- 顶栏排列文件名、同步状态点、查看范围和分组图标操作；每个图标保留悬浮提示与无障碍名称。撤销/重做在没有历史记录时禁用，窄栏自动换行；积木统计和属性/代码面板放在底部。
- 声明积木依次显示**用途修饰符 → 数据类型 → 变量名**。用途与类型均为下拉框，属性面板也使用下拉框；中文名称只作显示，保存 `static const`、`int32_t`、`char*`、`uint8_t*` 等 C++ 拼写。转换按 AST 拆分修饰符、类型和声明符，简单指针的 `*` 属于类型；引用、数组、函数指针、PROGMEM 及未知 typedef/模板类型保留原结构。多变量声明沿用外层共享类型，不向单个声明符插入第二个类型。点击白色字段直接编辑数值、名称、签名、变量声明符、运算符或循环条件；选中积木后打开 **积木属性**，可编辑完整多行原文、宏、注释和折叠的数据。点击 `if`、`switch`、调用或列表积木上的 **＋** 打开扩展菜单；属性面板和右键菜单也提供对应操作。
- 字段修改、方法切换及积木结构调整后，生成的有效 C++ 会短暂防抖并同步写入左侧源码缓冲区；写入前检查语法和当前源码版本，未完成的输入或外部改动不会覆盖源码。**撤销 / 重做** 操作当前画布；**生成 C++** 显示完整文件的草稿；**应用到源码** 可立即验证并应用当前草稿。返回源码后可正常保存；在积木标签中保存或关闭时选择“保存”，也会验证、应用并保存源文件。
- 切换函数范围或源码标签会保留草稿。单函数视图固定外层容器，避免意外脱离原位置；新积木必须连接到该容器。未连接表达式、必填插槽缺失、语法错误或无法安全重建的注释边界会阻止应用，并保留草稿。
- 修改过的积木标签显示未保存标记，关闭时使用编辑器原有保存/不保存/取消提示。重新载入需要明确点击 **放弃草稿并载入**。草稿属于当前编辑器会话，尚未提供应用重启后的草稿恢复；需要持久保存时使用保存操作。
- 源码同时被用户或其他功能修改时保留积木草稿并禁用应用。提交前同步比较源文件版本和完整文本，不会覆盖新版本；验证期间继续编辑积木也会停止旧提交。

### 积木快捷扩展

通过专用 Blockly 扩展 `cpp_quick_items` 提供快捷菜单：

- `if`：添加 `else if`、添加 `else`、移除空 `else`。连续追加时保留原有条件与分支，把新条件接在链尾、已有 `else` 之前；新增条件默认 `false`，可直接编辑。
- `switch`：添加 `case` 和 `default`，新增分支自带 `break;`。已有 `default` 时禁用重复添加；嵌套 switch 的 default 单独计算。新 case 追加到原分支序列末尾，保留已有贯穿行为和 default 位置。默认编号避开简单整数字面量，可编辑成所需常量；枚举别名等常量语义仍由工程编译验证。
- 调用和列表：一键增加参数或列表项，自动连接可编辑的 `0`。仅允许快捷移除末尾空插槽，防止丢弃已有表达式。
- 以上操作均按一次操作分组撤销/重做；已连接的分支内容不会被快捷移除。新增的 switch、case/default 也可从“逻辑”分类拖入；脱离 switch 的 case/default 会阻止生成和应用。

### 生成策略与边界

转换结果保存原始源码区间、完整字段和子节点插槽。未修改的部分直接复用原文；修改字段或连接时，只重建相应范围。新增代码使用 C++ 生成器；重排表达式时补上必要括号，无花括号的单语句分支扩展为多语句后自动添加花括号。整个文件中的其他函数、HTML、`PROGMEM` 和点阵数据不会因局部修改而重新格式化。新加的复杂语法也可通过原文积木表达。

采用专用 `cpp_preview_*` 积木，不自动匹配 Aily 硬件库积木，不产生 `.abi`，不运行旧 Arduino 生成器。语法检查不能替代工程编译、类型检查或硬件行为验证。未覆盖语法可以原文方式编辑，不能保证全部 C++ 都能细分为结构化积木。
